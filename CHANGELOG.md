# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.5.8]

- updated to modify dimension names for currents datasets from 'vxo'/'vyo' format to 'uo'/'vo'.

## [1.5.7]

- fixed bug from 1.5.6.

## [1.5.6]

- updated to accomodate for winds dataset with dimension named "valid_time" instead of "time".

## [1.5.5]

- Now tested for python 3.14.

## [1.5.4]

- Fixed deprecation notice related to old numpy version used in development.

## [1.5.3]

- Changed input type for Map dates to agree with Travel

## [1.5.2]

- Added utility functions for bounding box creation
- Fixed tests to work with hatch

## [1.5.1]

- Package release on PyPI and Conda.
- Updated for usage with Copernicus currents datasets with parameters `vxo` and `vyo`.
- Version used for upcoming Pytheas paper.

## [1.1.0] --  [1.4.0]

- Development versions and tests.

## [1.0.0] (May 2025)

- First release for CAA Conference 2025, with full software but not working as package.

## [0.1.0] - (2024)

- First release for development.
